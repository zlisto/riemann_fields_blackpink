# The Riemann Hypothesis over Finite Fields

An animated, narrated mini-course in 8 short videos, from "an elliptic curve is a torus" to Deligne's 1974 proof of the Weil conjectures.

**Watch:** https://zlisto.github.io/riemann_fields_blackpink/

1. An elliptic curve is a torus
2. Homology: counting holes
3. Cohomology: measuring loops
4. Counting points mod p
5. The Weil conjectures
6. Frobenius & Lefschetz
7. Étale cohomology
8. Deligne's proof

Each video is a plain HTML page that draws on a canvas and narrates with the browser's built-in speech synthesis (Chrome and Edge sound best). Keys: space play/pause, ← → chapters, m mute, c captions, f fullscreen.

No build step: serve the folder with any static server, e.g. `python -m http.server`.
